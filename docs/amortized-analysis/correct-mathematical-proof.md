# 동적배열 분할상환분석 - 정확한 수학적 증명

## 문제 정의

초기 용량 1인 동적배열에 n개의 요소를 삽입할 때의 총 비용과 분할상환 비용을 구하라.

## 학계의 정확한 표기법

### 출처
- **CLRS (Introduction to Algorithms)** Chapter 17: Amortized Analysis
- **Cornell University CS3110** Lecture 21: Amortized analysis and dynamic tables
- **Interview Cake**: Dynamic Array Amortized Analysis

## 정확한 증명

### 연산 정의

i번째 삽입의 비용 c_i:
```
c_i = {
  1           if 현재 용량 < 현재 크기 (복사 불필요)
  i           if 현재 용량 = 현재 크기 (복사 필요)
}
```

복사가 발생하는 시점: i-1이 2의 거듭제곱일 때
- i=2: 1개 복사 + 1개 삽입 = 2
- i=3: 2개 복사 + 1개 삽입 = 3
- i=5: 4개 복사 + 1개 삽입 = 5
- i=9: 8개 복사 + 1개 삽입 = 9
- i=17: 16개 복사 + 1개 삽입 = 17

### 총 비용 계산 (Aggregate Method)

n개 삽입의 총 비용:
```
C(n) = Σ(i=1 to n) c_i
     = (삽입 비용) + (복사 비용)
     = n + Σ(복사 비용)
```

### 복사 비용의 합

**핵심**: 복사가 발생한 시점에서 복사하는 개수

n개를 삽입할 때 (n ≥ 1):
```
복사 발생 시점:
- i=2:  1개 복사 (2^0)
- i=3:  2개 복사 (2^1)
- i=5:  4개 복사 (2^2)
- i=9:  8개 복사 (2^3)
- ...
- i=2^k+1: 2^k개 복사
```

여기서 k = ⌊log₂(n-1)⌋

**복사 비용 총합**:
```
Σ(복사) = Σ(j=0 to ⌊log₂(n-1)⌋) 2^j
```

### 경우 1: n이 2의 거듭제곱인 경우 (n = 2^k)

n = 2^k개를 삽입할 때:

**복사가 발생한 시점들**:
- i=2: 1개 (2^0)
- i=3: 2개 (2^1)
- i=5: 4개 (2^2)
- ...
- i=2^(k-1)+1: 2^(k-1)개

**마지막 복사는 언제?**
- i = 2^(k-1) + 1번째 삽입 시
- 용량 2^(k-1) → 2^k로 확장
- 2^(k-1) = n/2개를 복사

**복사 비용 합**:
```
Σ(복사) = 2^0 + 2^1 + 2^2 + ... + 2^(k-1)
        = 1 + 2 + 4 + ... + n/2
        = 2^k - 1
        = n - 1
```

**총 비용**:
```
C(n) = n + (n - 1) = 2n - 1
```

**분할상환 비용**:
```
A(n) = C(n) / n = (2n - 1) / n = 2 - 1/n
```

예시:
- n=2: (2×2-1)/2 = 3/2 = 1.5
- n=4: (2×4-1)/4 = 7/4 = 1.75
- n=8: (2×8-1)/8 = 15/8 = 1.875
- n=16: (2×16-1)/16 = 31/16 = 1.9375
- n=32: (2×32-1)/32 = 63/32 = 1.9688

### 경우 2: n이 2의 거듭제곱이 아닌 경우

n개를 삽입할 때, 2^k < n < 2^(k+1)이라고 하자.

**마지막 복사**:
- i = 2^k + 1번째 삽입 시 발생
- 2^k개를 복사

**복사 비용 합**:
```
Σ(복사) = 1 + 2 + 4 + ... + 2^(k-1) + 2^k
        = 2^(k+1) - 1
```

여기서 2^k < n < 2^(k+1)이므로:
```
n/2 < 2^k < n
```

따라서:
```
Σ(복사) = 2^(k+1) - 1 < 2n - 1
```

**총 비용**:
```
C(n) = n + Σ(복사) < n + 2n - 1 = 3n - 1
```

**분할상환 비용**:
```
A(n) < (3n - 1) / n = 3 - 1/n < 3
```

### Interview Cake의 표기법

Interview Cake는 더 직관적인 표기를 사용합니다:

m개 삽입 시:
```
복사 비용 = 1 + 2 + 4 + 8 + ... + m/2 + m
```

이것은 다음을 의미합니다:
- 마지막 복사가 **m개를 복사**하는 경우를 포함
- 즉, m+1번째 요소를 삽입하려 할 때의 복사 비용

**기하급수 계산**:
```
m + m/2 + m/4 + ... + 4 + 2 + 1
= m × (1 + 1/2 + 1/4 + 1/8 + ...)
= m × 2
= 2m
```

**총 비용**:
```
C(m) = m (삽입) + 2m (복사) = 3m
```

**분할상환 비용**:
```
A(m) = 3m / m = 3
```

## 왜 두 가지 답이 나오는가?

### n개 삽입 완료 시점 (2 - 1/n)

n개를 **이미 삽입 완료**한 상태:
- 용량은 ≥ n
- 마지막 복사는 용량 n/2 → n 확장 시
- 복사 합: 1 + 2 + ... + n/2 = n - 1
- 분할상환: (2n - 1) / n ≈ 2

### n+1번째 삽입 시점 (3)

**만약 n이 2의 거듭제곱이라면**:
- n+1번째 요소 삽입 시 복사 발생
- n개를 복사해야 함
- 이 순간까지의 복사 합: 1 + 2 + ... + n = 2n - 1
- 분할상환: (3n - 1) / n ≈ 3

## 실제 데이터와의 비교

### n=32인 경우

**32개 삽입 완료**:
- 복사: 1 + 2 + 4 + 8 + 16 = 31
- 총 비용: 32 + 31 = 63
- 분할상환: 63/32 = 1.9688 ✓

**17번째 삽입 시**:
- 이 순간 16개를 복사
- 누적 복사: 1 + 2 + 4 + 8 + 16 = 31
- 누적 비용: 17 + 31 = 48
- 분할상환: 48/17 = 2.82 ⚠️

**왜 2.82인가?**
- 17번째 삽입 = 2^4 + 1
- 방금 2^4 = 16개를 복사
- 아직 다음 2^4번의 저렴한 삽입이 오지 않음
- 따라서 일시적으로 높은 평균

## 정확한 상한 증명

### 정리 (Theorem)

동적배열에 n개 요소를 삽입하는 총 비용은 **최대 3n**이다.

### 증명

임의의 n에 대해, k = ⌊log₂(n)⌋라 하자.

복사 비용:
```
Σ(복사) ≤ 1 + 2 + 4 + ... + 2^k
        = 2^(k+1) - 1
        < 2 × 2^k
        ≤ 2n
```

총 비용:
```
C(n) = n + Σ(복사) < n + 2n = 3n
```

분할상환 비용:
```
A(n) = C(n) / n < 3n / n = 3
```

따라서 **O(1) 분할상환 시간, 상한 3**.

## 회계 방법 (Accounting Method)

각 삽입에 **3 크레딧**을 부과:
- 1 크레딧: 즉시 삽입에 사용
- 2 크레딧: 미래의 복사 비용을 위해 저축

**불변식**: 배열의 후반부 절반(n/2개)의 요소는 각각 2 크레딧을 보유.

복사 발생 시:
- n개 요소를 복사해야 함
- 후반부 n/2개 요소가 각각 2 크레딧 보유
- 총 n 크레딧으로 n개 복사 비용 지불 ✓

## 퍼텐셜 방법 (Potential Method)

퍼텐셜 함수:
```
Φ(T) = 2 × size - capacity
```

초기: Φ(∅) = 0

**복사 없는 삽입**:
- 실제 비용: 1
- ΔΦ = 2 × 1 - 0 = 2
- 분할상환 비용: 1 + 2 = 3

**복사 있는 삽입** (size = capacity = n):
- 실제 비용: n + 1
- 복사 후: size = n+1, capacity = 2n
- ΔΦ = (2(n+1) - 2n) - (2n - n) = 2 - n
- 분할상환 비용: (n + 1) + (2 - n) = 3

**모든 경우에 분할상환 비용 = 3**

## 결론

### 정확한 표현

**n이 2의 거듭제곱일 때**:
```
복사 비용 = 1 + 2 + 4 + ... + n/2 = n - 1
총 비용 = 2n - 1
분할상환 비용 = 2 - 1/n ≈ 2
```

**일반적인 n에 대해**:
```
복사 비용 ≤ 1 + 2 + 4 + ... + n < 2n
총 비용 < 3n
분할상환 비용 < 3
```

**실제 동작**:
- 복사 직후: 일시적으로 높은 분할상환 비용 (최대 ~2.82)
- 2의 거듭제곱 위치: 정확히 2 - 1/n
- 점근적: 2에 수렴

### 최종 답

> 동적배열의 삽입 연산은 **O(1) 분할상환 시간**을 가지며,
> 상한은 **3**, 평균은 **약 2**입니다.
