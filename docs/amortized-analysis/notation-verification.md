# 복사 비용 표기법 검증

## 질문
복사 비용이 `1 + 2 + 4 + 8 + ...`이면 `2^0 + 2^1 + 2^2 + ...` 흐름으로 간다면, 마지막 항을 **n/2**로 표기하는 것이 맞는가?

## 답변: ✅ 맞습니다!

## 상세 검증

### 1. 구체적 예시 분석

#### n = 32인 경우

```
초기 용량: 1

연산 2: 크기 1 → 2로 확장, 1개 복사
연산 3: 크기 2 → 4로 확장, 2개 복사
연산 5: 크기 4 → 8로 확장, 4개 복사
연산 9: 크기 8 → 16로 확장, 8개 복사
연산 17: 크기 16 → 32로 확장, 16개 복사  ← 마지막 복사

복사 개수: 1, 2, 4, 8, 16
          2^0, 2^1, 2^2, 2^3, 2^4

마지막 항: 16 = 32/2 = n/2 ✓
```

#### n = 64인 경우

```
복사 개수: 1, 2, 4, 8, 16, 32
          2^0, 2^1, 2^2, 2^3, 2^4, 2^5

마지막 항: 32 = 64/2 = n/2 ✓
```

#### n = 128인 경우

```
복사 개수: 1, 2, 4, 8, 16, 32, 64
          2^0, 2^1, 2^2, 2^3, 2^4, 2^5, 2^6

마지막 항: 64 = 128/2 = n/2 ✓
```

### 2. 수학적 증명

n개 요소를 삽입할 때 (n = 2^k 가정):

**복사가 발생하는 용량 확장:**
```
1 → 2   : 1개 복사  = 2^0
2 → 4   : 2개 복사  = 2^1
4 → 8   : 4개 복사  = 2^2
8 → 16  : 8개 복사  = 2^3
...
n/2 → n : n/2개 복사 = 2^(k-1)
```

**마지막 복사:**
- 용량이 **n/2**일 때, n/2번째 요소까지 채워짐
- (n/2 + 1)번째 요소 삽입 시 용량 확장 발생
- **n/2개 요소를 복사**하고 용량을 n으로 확장

**지수 표현:**
```
n = 2^k이므로
n/2 = 2^k / 2 = 2^(k-1)

따라서 마지막 복사 개수 = 2^(k-1) = n/2
```

### 3. 등비급수의 합

```
S = 1 + 2 + 4 + 8 + ... + n/2
  = 2^0 + 2^1 + 2^2 + ... + 2^(k-1)

첫째항: a = 1
공비: r = 2
항의 개수: k
마지막 항: 2^(k-1) = n/2

등비급수 공식:
S = a(r^k - 1) / (r - 1)
  = 1(2^k - 1) / (2 - 1)
  = 2^k - 1
  = n - 1
```

### 4. 잘못된 표기와 비교

| 표기 | 의미 | 합 | 정확도 |
|------|------|----|----|
| `1 + 2 + 4 + ... + n/2` | 용량 n/2까지 | n - 1 | ✅ 정확 |
| `1 + 2 + 4 + ... + n` | 용량 n까지 | 2n - 1 | ❌ 한 항 많음 |
| `2^0 + 2^1 + ... + 2^(k-1)` | k항 (n=2^k) | n - 1 | ✅ 정확 |
| `2^0 + 2^1 + ... + 2^k` | k+1항 | 2n - 1 | ❌ 한 항 많음 |

**왜 n까지가 아닌 n/2까지인가?**

```
n개 요소를 삽입하는 동안의 복사:
- n번째 요소 삽입 시점에는 이미 용량이 n 이상
- 따라서 용량 n → 2n 확장은 발생하지 않음
- 마지막 확장은 용량 n/2 → n

예시 (n=32):
- 32번째 요소 삽입 시 용량은 이미 32
- 복사 없이 그냥 추가됨
- 33번째 요소 삽입 시에야 32 → 64 확장 발생 (범위 밖)
```

### 6. 표기법 권장사항

**가장 명확한 표기 (추천):**
```
1 + 2 + 4 + 8 + ... + n/2  (n = 2^k일 때)
```

**대안적 표기들:**
```
2^0 + 2^1 + 2^2 + ... + 2^(k-1)  (n = 2^k일 때)

Σ(i=0 to k-1) 2^i  (n = 2^k일 때)

Σ(i=0 to log₂(n)-1) 2^i  (n = 2^k일 때)
```

**완전한 표기 (범위 포함):**
```
Σ(i=0 to ⌊log₂(n)⌋-1) 2^i  (모든 n ≥ 1)
```

## 결론

### ✅ 표기법 검증 결과

**README.md의 표기:**
```
복사 비용: 1 + 2 + 4 + 8 + ... + n/2 = n - 1 (등비급수의 합)
```

**검증:**
- ✅ `n/2` 표기는 **완전히 정확**합니다
- ✅ 마지막 복사는 정확히 n/2개 요소를 복사합니다
- ✅ 등비급수의 마지막 항은 2^(k-1) = n/2입니다 (n = 2^k일 때)
- ✅ 합은 정확히 n - 1입니다

### 핵심 이유

> **n개 요소를 삽입할 때**, 용량은 **n까지만 확장**되고 **2n으로는 확장되지 않습니다**.
> 따라서 마지막 복사는 용량 **n/2 → n** 확장 시 발생하며, 이때 **n/2개**를 복사합니다.

### 시각적 요약

```
용량 1    → 용량 2    : 1개 복사   (2^0)
용량 2    → 용량 4    : 2개 복사   (2^1)
용량 4    → 용량 8    : 4개 복사   (2^2)
용량 8    → 용량 16   : 8개 복사   (2^3)
...
용량 n/2  → 용량 n    : n/2개 복사 (2^(k-1))
                        ↑
                    마지막 복사!
```

**표기는 완벽하게 정확합니다!** 👍
