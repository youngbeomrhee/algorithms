| 9 | 8 | 용량 8 → 16으로 확장 |
| 17 | 16 | 용량 16 → 32로 확장 |

### 2. 비용 분류

**연산별 빈도:**
- 비용 1 (단순 추가): 27회 (84.4%)
- 비용 > 1 (복사 + 추가): 5회 (15.6%)

**총 비용 구성:**
- 추가 비용: 32 (모든 연산)
- 복사 비용: 1 + 2 + 4 + 8 + 16 = 31
- **총 비용: 63**


**핵심 패턴:**

- 최종값: 1.97 (n=32)

## 수학적 분석 (학계 표준)

### 총 비용 공식

#### 경우 1: n = 2^k (2의 거듭제곱)

n = 2^k개 삽입 완료 시:

```
삽입 비용 = n

복사 발생 시점:
- 2번째: 1개 복사
- 3번째: 2개 복사
- 5번째: 4개 복사
- ...
- 2^(k-1)+1번째: n/2개 복사

복사 비용 = 1 + 2 + 4 + ... + n/2
          = 2^0 + 2^1 + ... + 2^(k-1)
          = 2^k - 1
          = n - 1

총 비용 = n + (n - 1) = 2n - 1
```

#### 경우 2: 2^k < n < 2^(k+1) (일반적인 n)

```
복사 비용 ≤ 1 + 2 + 4 + ... + 2^k < 2n
총 비용 < 3n
```

### 분할상환 비용 계산

```
n = 2^k일 때:
  분할상환 = (2n - 1) / n = 2 - 1/n
  예: n=32 → 63/32 = 1.9688

일반적인 n:
  분할상환 < 3n / n = 3
  예: n=17 → 48/17 = 2.8235
```

**핵심 통찰 (CLRS, Cornell):**
- **2의 거듭제곱 위치**: 정확히 2 - 1/n (최저점)
- **복사 직후**: 일시적으로 상승 (최대 ~2.82)
- **상한**: 3 (모든 n에 대해 보장)
- **평균**: 점근적으로 2에 수렴

### 점근적 분석

- **최악의 경우**: O(n) - 단일 삽입에서 모든 요소 복사
- **분할상환 비용**: O(1) - 평균적으로 상수 시간
- **총 n개 삽입**: O(n) - 선형 시간

## 비교: 확장 전략에 따른 차이

| 전략 | 확장 방법 | 분할상환 비용 | 공간 낭비 |
|------|-----------|---------------|-----------|
| 2배 확장 | capacity × 2 | O(1) = 2 | 최대 50% |
| 1.5배 확장 | capacity × 1.5 | O(1) ≈ 3 | 최대 33% |
| 고정 증가 | capacity + k | O(n) | 최소 |

**결론:** 2배 확장이 분할상환 비용과 공간 효율의 최적 균형을 제공합니다.

## 연습 문제

1. **초기 용량이 2인 경우**, 16개 요소 삽입 시 총 비용은?
   - 답: 2 + 16 + (2 + 4 + 8) = 32

2. **3배 확장 전략**을 사용한다면 분할상환 비용은?
   - 답: 여전히 O(1), 하지만 상수가 더 작음 (약 1.5)

3. **n = 1000**일 때, 최악의 경우와 분할상환 비용의 차이는?
   - 최악: O(1000) = 1000
   - 분할상환: O(1) ≈ 2
