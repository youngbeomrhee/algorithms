# 분할상환 비용의 정확한 이해

## 질문: 왜 실제 분할상환 비용이 2를 초과하는가?

## 답변

### 공식 `2 - 1/n`의 정확한 의미

**`(2n - 1) / n = 2 - 1/n`**은 **n개 삽입 완료 시점의 평균 비용**입니다.

하지만 이것은:
- ✅ n이 **2의 거듭제곱**일 때 정확히 맞음
- ❌ 모든 중간 시점에서 항상 이 값인 것은 아님

### 실제 분할상환 비용 변화 (n=1~32)

| n | 누적비용 | 분할상환 | 2-1/n | 복사 발생 |
|---|----------|----------|-------|-----------|
| 1 | 1 | 1.00 | 1.00 | - |
| 2 | 3 | 1.50 | 1.50 | ✓ (1개) |
| 3 | 6 | 2.00 | 1.67 | ✓ (2개) ⚠️ |
| 4 | 7 | 1.75 | 1.75 | - |
| 5 | 12 | **2.40** | 1.80 | ✓ (4개) ⚠️ |
| 8 | 15 | 1.88 | 1.88 | - |
| 9 | 24 | **2.67** | 1.89 | ✓ (8개) ⚠️ |
| 16 | 31 | 1.94 | 1.94 | - |
| 17 | 48 | **2.82** | 1.94 | ✓ (16개) ⚠️ |
| 32 | 63 | 1.97 | 1.97 | - |

### 패턴 분석

#### 1. 2의 거듭제곱 위치 (2, 4, 8, 16, 32)
- ✅ 정확히 `2 - 1/n` 공식 일치
- 이유: 이 시점에서는 복사가 발생하지 않음
- 예: n=16일 때 16번째 요소는 그냥 추가됨 (용량 16이 딱 맞음)

#### 2. 복사 직후 (3, 5, 9, 17)
- ⚠️ 공식보다 큼 (2를 초과)
- 이유: 막 큰 복사가 발생했고, 아직 평균이 상쇄되지 않음
- 예: n=17일 때, 방금 16개를 복사했으므로 평균이 급증

### 수학적 설명

#### n=17인 경우를 자세히 보면:

```
17번째 삽입 시:
- 삽입 비용: 1
- 복사 비용: 16 (기존 16개 모두 복사)
- 이번 연산 비용: 17

누적 비용: 31 (16번까지) + 17 = 48
분할상환: 48 / 17 = 2.82

이론값 2 - 1/17 = 1.94와 차이: 0.88
```

#### 왜 차이가 나는가?

**`2 - 1/n` 공식은 n이 2의 거듭제곱일 때의 "최종 도착점"입니다.**

복사 직후에는:
1. 방금 큰 비용(n/2)이 추가됨
2. 아직 그 이후의 저렴한 연산들(비용 1)이 평균을 낮추지 못함
3. 따라서 일시적으로 평균이 상승

이후 비용 1인 연산들이 계속되면서 평균이 점진적으로 하락합니다.

### 더 정확한 공식

#### 일반적인 n에 대해

n번째 삽입 후의 누적 비용을 C(n)이라 하면:

```
C(n) = n + Σ(복사 비용)

n = 2^k일 때:
  Σ(복사 비용) = 1 + 2 + 4 + ... + n/2 = n - 1
  C(n) = n + (n - 1) = 2n - 1
  분할상환 = (2n - 1) / n = 2 - 1/n

n = 2^k + 1일 때 (복사 직후):
  Σ(복사 비용) = 1 + 2 + 4 + ... + n/2 (반올림) + n/2
  복사가 방금 발생했으므로 추가 비용이 큼
  분할상환 > 2
```

### 상한 증명

**주장**: 분할상환 비용은 최대 3 미만입니다.

**증명**:

n번째 삽입 후, 최악의 경우는 방금 n/2개를 복사한 경우입니다.

```
C(n) ≤ n + (1 + 2 + 4 + ... + n/2 + n/2)
     = n + (n - 1 + n/2)
     = 2.5n - 1

분할상환 = (2.5n - 1) / n
         = 2.5 - 1/n
         < 2.5 (실제로는 더 작음)
```

실제 최대값은 약 2.82입니다 (n=17일 때).

### 점근적 분석

**핵심**: n이 충분히 크면, 복사 직후의 일시적 급등은 무시할 수 있습니다.

```
n → ∞일 때:
- 2의 거듭제곱 위치: 2 - 1/n → 2
- 복사 직후 최대값: 2.5 - 1/n → 2.5
- 하지만 빈도가 낮아 평균적으로 2에 수렴
```

### 정확한 상한 (Tighter Bound)

더 정밀한 분석:

복사가 발생한 직후(n = 2^(k-1) + 1):
```
C(2^(k-1) + 1) = (2^(k-1) + 1) + (2^k - 1)
                = 3 × 2^(k-1)

분할상환 = 3 × 2^(k-1) / (2^(k-1) + 1)
         = 3 / (1 + 1/2^(k-1))
         → 3 (k가 클 때)
```

하지만 실제로는 **3에 도달하지 않습니다**. 최대값은 약 **2.82**입니다.

## 결론

### 정확한 분할상환 비용

1. **2의 거듭제곱 위치**: 정확히 `2 - 1/n`
2. **복사 직후**: 일시적으로 증가 (최대 약 2.82)
3. **점근적**: 2에 수렴
4. **상한**: 3 (이론), 실제로는 약 2.82

### 올바른 표현

- ❌ "분할상환 비용은 항상 2 - 1/n"
- ✅ "분할상환 비용은 O(1)이며, 상한은 3입니다"
- ✅ "n이 2의 거듭제곱일 때 정확히 2 - 1/n에 도달"
- ✅ "평균적으로 약 2, 최대 약 3"

## 요약

> **분할상환 비용 = 2 - 1/n**은 n이 2의 거듭제곱일 때의 값입니다.
>
> 실제로는 복사 직후 일시적으로 2를 초과하지만,
> **점근적으로 O(1)이며 상한은 3입니다**.
>
> 이것이 분할상환분석의 핵심: 가끔 발생하는 비싼 연산을 평균으로 상쇄합니다.
